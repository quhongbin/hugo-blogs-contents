### 1.2 知识点系统精讲 {#1-dot-2-知识点系统精讲}


#### 1.2.1 基本概念与术语 {#1-dot-2-dot-1-基本概念与术语}

| 术语                | 定义（教材口径）        | 辨析                       |
|-------------------|-----------------|--------------------------|
| 数据 (data)         | 能输入计算机并被处理的符号总称 | 信息的载体                 |
| 数据元素 (data element) | 数据的 **基本单位** ，一个整体进行处理 | 又称记录、结点、顶点       |
| 数据项 (data item)  | 组成数据元素的、有独立含义的 **最小单位** | 又称域、字段；元素 &gt; 项 |
| 数据对象            | 性质相同的数据元素的集合，是数据的子集 | 如整数集合                 |
| 数据结构            | 相互之间存在一种或多种特定关系的数据元素的集合 | 含 **逻辑结构 + 存储结构 + 运算** 三要素 |


#### 1.2.2 逻辑结构（与存储无关，描述元素间逻辑关系） {#1-dot-2-dot-2-逻辑结构-与存储无关-描述元素间逻辑关系}

```text
逻辑结构
├── 线性结构：一对一（线性表、栈、队列、串）
└── 非线性结构
    ├── 集合：元素间仅"同属一个集合"
    ├── 树形结构：一对多（层次关系）
    └── 图状（网状）结构：多对多
```


#### 1.2.3 存储结构（物理结构，逻辑结构在计算机中的映像） {#1-dot-2-dot-3-存储结构-物理结构-逻辑结构在计算机中的映像}

| 存储结构 | 思想                      | 特点            |
|------|-------------------------|---------------|
| 顺序存储 | 逻辑相邻 → 物理地址相邻，借助 **相对位置** | 可随机存取；插删需移动 |
| 链式存储 | 借助 **指针** 表示逻辑关系，物理上可不相邻 | 插删快；不能随机存取 |
| 索引存储 | 另建索引表（关键字+地址） | 检索快；占额外空间 |
| 散列（哈希）存储 | 由关键字通过哈希函数直接算出地址 | 查找平均 O(1)；需处理冲突 |

> **结论** ：同一种逻辑结构可采用不同存储结构。如线性表既可顺序存储（顺序表），也可链式存储（链表）。


#### 1.2.4 数据类型与抽象数据类型（ADT） {#1-dot-2-dot-4-数据类型与抽象数据类型-adt}

-   **数据类型** ：一个值的集合 + 定义在该集合上的一组操作（如 C 的 `int` ）。分 **原子类型** （不可再分）与 **结构类型** （可再分）。
-   **抽象数据类型 ADT** ：用户自定义、表示与实现分离的数学模型，三要素 = **数据对象 D + 数据关系 S + 基本操作 P** 。
-   描述格式（教材）： `ADT 名称 { 数据对象；数据关系；基本操作 } ADT 名称` ，特性是 **数据抽象** 与 **信息隐蔽** 。


#### 1.2.5 算法（Algorithm） {#1-dot-2-dot-5-算法-algorithm}

**定义** ：对特定问题求解步骤的一种描述，是指令的有限序列。

**五个重要特性（必背）**

| 特性 | 含义                       |
|----|--------------------------|
| 有穷性 | 有限步后结束，每步在有限时间内完成 |
| 确定性 | 每条指令含义明确，无二义性；相同输入必得相同输出 |
| 可行性 | 每步都可通过已实现的基本运算有限次执行完成 |
| 输入 | 有 **0 个或多个** 输入     |
| 输出 | **至少 1 个** 输出（没有输出的算法毫无意义） |

**算法设计要求** ：正确性、可读性、健壮性（对非法输入能适当处理）、高效率与低存储量需求。

> 辨析："有穷性"是算法与程序的根本区别——操作系统程序是无限循环运行的，它是程序而不是算法。


#### 1.2.6 算法效率度量：时间复杂度与空间复杂度 {#1-dot-2-dot-6-算法效率度量-时间复杂度与空间复杂度}

**（1）事后统计 vs 事前分析估算** ：教材采用 **事前分析估算** ，只看问题规模 n 与算法本身，与机器、语言无关。

**（2）语句频度** ：一条语句重复执行的次数。算法总执行量是所有语句频度之和。

**（3）大 O 记号（渐近时间复杂度）** ：若存在常数 C、n₀，使 n≥n₀ 时 T(n)≤C·f(n)，记 **T(n)=O(f(n))** 。只取 **最高阶项、去系数、去低阶项** 。

常见量级排序（必背，从小到大）：

```text
O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)
```

**（4）三种时间复杂度**

| 类型    | 含义                          |
|-------|-----------------------------|
| 最好时间复杂度 | 最有利输入下的下界            |
| 最坏时间复杂度 | 最不利输入下的上界（ **最有保证，常作为评价依据** ） |
| 平均时间复杂度 | 所有输入等概率时的数学期望    |

**（5）经典频度结论**

| 程序结构                            | 频度 / 复杂度                           |
|---------------------------------|------------------------------------|
| 单层循环 `for(i=1;i<=n;i++)`        | n，O(n)                                 |
| 两层嵌套、各自到 n                  | n²，O(n²)                               |
| `for(i=1;i<=n;i*=2)`                | ⌊log₂n⌋+1， **O(log n)** （倍增/折半变量是对数阶标志） |
| `i=1;while(i<=n) i*=3`              | O(log₃n)=O(log n)（底数可换，忽略常数） |
| `for(i=0;i<n;i++) for(j=0;j<i;j++)` | n(n−1)/2，O(n²)                         |

**（6）空间复杂度 S(n)=O(g(n))** ：算法运行所需 **辅助空间** （输入数据本身所占空间不计）。只需有限个临时变量 → O(1)，称 **原地工作** ；递归算法的辅助空间主要是 **递归工作栈** ，深度为 n 时 S(n)=O(n)。


#### 1.2.7 递归 {#1-dot-2-dot-7-递归}

-   **递归定义两要素** ：① **递归出口（边界条件）** ——直接给出解；② **递归体（递归步骤）** ——把问题化为更小规模的同类问题。
-   执行机制：系统自动设置 **递归工作栈** ，每层保存返回地址、实参、局部变量（活动记录/栈帧）。
-   优缺点：结构清晰、代码简短、正确性易证；但有函数调用开销、栈深度受限制。
-   **递归→非递归** ：① 单向递归/尾递归可直接改循环；② 复杂回溯型递归用 **用户自定义栈** 显式模拟。
-   经典递归：阶乘、斐波那契、汉诺塔（n 片金片移动 **2ⁿ−1** 次）、 Ackermann。

2.  设计递归算法：逆序输出一个不带头结点的单链表中所有结点的数据（只允许遍历一次，不允许修改链表）。


### 1.4 答案与详解 {#1-dot-4-答案与详解}

**单选** ：1.B（数据项是最小单位，数据元素是基本单位）　2.B　3.C（树是非线性）　4.A　5.C（i 倍增，执行 ⌊log₂n⌋+1 次）　6.C（指数阶大于多项式阶）　7.B（取最高阶去系数）　8.B　9.D　10.C

**填空** ：1. 存储（物理）　2. 索引存储　3. 基本操作（操作集合）　4. 可行性　5. n²；O(n²)　6. 空间；原地工作　7. 递归体（递归步骤）

**解答**

1.  三重循环计数为 Σᵢ₌₁ⁿ Σⱼ₌₁ⁱ Σₖ₌₁ʲ 1 = Σᵢ₌₁ⁿ i(i+1)/2 = n(n+1)(n+2)/6，故频度为 **n(n+1)(n+2)/6** ，最高阶 n³， **T(n)=O(n³)** 。
2.  **10000(O(1)) &lt; log₂n &lt; n &lt; nlog₂n &lt; n² &lt; 2ⁿ &lt; n!** 。
3.  ```C
       long fact(int n){
           if(n==0) return 1;      // 递归出口：0!=1
           return n*fact(n-1);     // 递归体：n!=n*(n-1)!
       }
    ```
    递归深度 n，每层一个栈帧， **空间复杂度 O(n)** ，时间 O(n)。

**算法阅读**

(1) fun(16)=fun(8)+1=fun(4)+2=fun(2)+3=fun(1)+4=0+4= **4** ；调用链 16→8→4→2→1 后逐层返回 1、2、3、4。
(2) 每做一次参数减半， **时间 O(log₂n)** ；递归栈深度 ⌊log₂n⌋+1， **空间 O(log₂n)** 。

**算法设计**

1.  ```C
       long Fib(int n){
           long f0=0, f1=1, f; int i;
           if(n==0) return 0;
           if(n==1) return 1;
           for(i=2;i<=n;i++){ f=f0+f1; f0=f1; f1=f; }
           return f1;
       }
    ```
    只用 3 个滚动变量，时间 O(n)，空间 O(1)。
2.  ```C
       void ReversePrint(LNode *p){   // p 初始指向首元结点
           if(p==NULL) return;        // 递归出口
           ReversePrint(p->next);     // 先递归到表尾
           printf("%d ", p->data);    // 返回途中输出，天然逆序
       }
    ```
    要点："先递归、后访问"得到逆序；时间 O(n)，栈空间 O(n)。

## 第二章 线性表 {#第二章-线性表}


### 2.1 考情导航 {#2-dot-1-考情导航}

-   **识记** ：线性表的逻辑结构定义与特点；顺序表、单链表、循环链表、双向链表、静态链表的结构。
-   **领会** ：头指针与头结点的区别；顺序存储与链式存储的优缺点及适用场合。
-   **简单应用** ：顺序表插入/删除的元素移动量计算；链表指针操作过程图示。
-   **综合应用** ：单链表建表、查找、插入、删除、逆置、合并、归并等算法设计（ **算法设计题高频章** ）。


### 2.2 知识点系统精讲 {#2-dot-2-知识点系统精讲}


#### 2.2.1 线性表的逻辑结构 {#2-dot-2-dot-1-线性表的逻辑结构}

**定义** ：n（n≥0）个数据元素的有限序列 (a₁, a₂, …, aᵢ, …, aₙ)。n=0 时为空表。

**四大特点**

1.  存在唯一的"第一个"（首元）元素和唯一的"最后一个"元素；
2.  除首元外，每个元素有且仅有一个 **直接前驱** ；
3.  除尾元外，每个元素有且仅有一个 **直接后继** ；
4.  元素间是 **一对一** 的线性关系。


#### 2.2.2 线性表的顺序存储——顺序表 {#2-dot-2-dot-2-线性表的顺序存储-顺序表}

**（1）结构** ：一组地址连续的存储单元依次存放，逻辑相邻 ⇔ 物理相邻。

```C
#define maxSize 100
typedef int ELEMType;
typedef struct {
    ELEMType data[maxSize];
    int length;          // 当前元素个数
} SqList;
```

**（2）随机存取地址公式（必考）** ：设每个元素占 L 个单元，首元素 a₁ 地址为 LOC(a₁)，则

```text
LOC(aᵢ) = LOC(a₁) + (i−1)·L        （下标 1 起）
LOC(aᵢ) = LOC(a₀) + i·L            （下标 0 起）
```

存取任一元素时间均为 **O(1)** ，故称 **随机存取** 结构。

**（3）插入算法与移动量** ：在第 i 个位置（1≤i≤n+1）插入，需把 aₙ…aᵢ 共 **n−i+1** 个元素后移。等概率（共 n+1 个插入位置，概率 1/(n+1)）时平均移动次数：

```text
E_insert = Σᵢ₌₁ⁿ⁺¹ (n−i+1)/(n+1) = n/2，时间 O(n)
```

**（4）删除算法与移动量** ：删除第 i 个元素（1≤i≤n），需把 aᵢ₊₁…aₙ 共 **n−i** 个元素前移。等概率（1/n）时：

```text
E_delete = Σᵢ₌₁ⁿ (n−i)/n = (n−1)/2，时间 O(n)
```

**（5）按值查找** ：逐个比较，等概率下成功平均比较 (n+1)/2 次，O(n)。


#### 2.2.3 线性表的链式存储 {#2-dot-2-dot-3-线性表的链式存储}

**（1）单链表结点**

```C
typedef struct LNode {
    ELEMType data;
    struct LNode *next;
} LNode, *LinkList;
```

**（2）头指针 vs 头结点（高频辨析）**

| 概念     | 含义                               | 作用                                    |
|--------|----------------------------------|---------------------------------------|
| 头指针 head | 指向链表第一个结点的 **指针** ，是链表的标识 | 链表必有的"入口"，链表为空时 head=NULL  |
| 头结点   | 首元结点 **之前** 附加的一个同型结点，data 域常空或存长度 | ① 使空表/非空表操作统一；② 使首元结点处的插入删除与其他位置一致，无需特判 |
| 首元结点 | 存放第一个数据元素 a₁ 的结点       | —                                       |

带头结点时：空表判定 `head->next==NULL` ；不带头结点时：空表判定 `head==NULL` 。

**（3）两种建表法**

-   **头插法** ：新结点始终插在最前面 `s->next=head->next; head->next=s;` 。特点：建表次序与输入次序 **相反** ，可用于链表逆置。
-   **尾插法** ：附设尾指针 rear， `rear->next=s; rear=s;` ，建表次序与输入 **相同** ，结束时 `rear->next=NULL` 。

**（4）查找** ：按序号 GetElem(L,i)、按值 LocateElem(L,e)，均需从头沿 next 走， **O(n)** ，链表是 **顺序存取** 。

**（5）插入（在 p 所指结点之后插入 s，后插法）**

```C
s->next = p->next; p->next = s;     // 两条语句顺序不能颠倒！
```

在 p **之前** 插入（前插法）：需找到 p 的前驱 q（O(n)），或用"后插+交换数据"技巧：先把 s 插到 p 后，再交换 s-&gt;data 与 p-&gt;data。

**（6）删除 p 的后继结点 q**

```C
q=p->next; p->next=q->next; free(q);
```


#### 2.2.4 循环链表与双向链表 {#2-dot-2-dot-4-循环链表与双向链表}

**（1）循环单链表** ：尾结点 next 指向头结点形成环。判空： `head->next==head` 。
常改用 **尾指针 rear** 标识：找表头 O(1)（ `rear->next` 即头结点）、找表尾 O(1)， **合并两个循环链表只需 O(1)** 。

**（2）双向链表结点**

```C
typedef struct DNode { ELEMType data; struct DNode *prior,*next; } DNode, *DLinkList;
```

-   双向链表插入（在 p 之后插 s）， **指针链接顺序** ：
    ```C
      s->next=p->next; s->prior=p;
      p->next->prior=s; p->next=s;
    ```
-   删除 p 的后继 q： `p->next=q->next; q->next->prior=p; free(q);`
-   双向循环链表：prior、next 均成环。

**（3）静态链表** ：用数组模拟链表，结点含 data 与 **游标 cur** （存"下一个元素的数组下标"，−1 表示表尾）。优点：不使用指针也能实现链式结构，适用于不支持指针的语言 / 固定容量场合。


#### 2.2.5 顺序表与链表比较（必背结论表） {#2-dot-2-dot-5-顺序表与链表比较-必背结论表}

| 比较维度 | 顺序表               | 链表                |
|------|-------------------|-------------------|
| 存取方式 | **随机存取** O(1)    | **顺序存取** ，定位 O(n) |
| 逻辑/物理关系 | 逻辑相邻且物理相邻   | 逻辑相邻靠指针，物理任意 |
| 插入删除 | 平均移动约一半元素，O(n) | 找位置 O(n)，改指针本身 O(1) |
| 空间分配 | 静态需预分配，可能浪费/溢出；动态可扩容 | 按需动态申请，指针域有额外开销 |
| 存储密度 | 高（=1）             | &lt;1（指针占空间） |
| 适用场景 | 表长稳定、查询多、少插删 | 长度变化大、频繁插删 |

### 2.4 答案与详解 {#2-dot-4-答案与详解}

**单选** ：1.A　2.B　3.B　4.C　5.B　6.B（先连后断，顺序颠倒会丢链）　7.B（头插得逆序）　8.C（rear 直接指向尾）　9.B　10.B

**填空** ：1. 顺序表（顺序存储）；链表（链式存储）　2. `L->next==NULL` ； `L==NULL`　3. n/2　4. `p->next=p->next->next` （或 `q=p->next; p->next=q->next` ）　5. `p`　6. 尾（rear）

**解答**

1.  步骤：① 判断表满与 i 合法性；② 从最后元素起，将 aₙ…aᵢ 依次后移一位；③ L.data[i−1]=e（0 基下标）；④ length++。共移动 n−i+1 个，等概率平均 n/2 个，故 O(n)。
2.  思路一（找前驱）：从表头遍历找到 p 的前驱 q，再做后插，时间 O(n)。思路二（后插+交换，O(1)）：
    ```C
       s->next=p->next; p->next=s;
       tmp=p->data; p->data=s->data; s->data=tmp;
    ```
3.  程序每次删除 p 的后继后 p 再后移，即 **隔一个删一个** ，结果： **(a,c,e)** 。

**算法阅读**

(1) `p->next=q->next` ；(2) `pre=q` 。
(2) 这是 **相邻两两交换位置** （把偶数位结点逐个提到奇数位之前）：输出 **2→1→4→3→6→5** ；功能为成对交换相邻结点。

**算法设计**

1.  头插法思想就地逆置：
    ```C
       void Reverse(LinkList L){
           LNode *p=L->next, *q;
           L->next=NULL;            // 先把原链断开，新链初始为空
           while(p){
               q=p->next;           // 保存下一个
               p->next=L->next; L->next=p;  // 头插到新链
               p=q;
           }
       }
    ```
    每结点处理一次，时间 O(n)，只用有限指针，空间 O(1)。
2.  双指针归并（复用结点）：
    ```C
       void MergeList(LinkList La,LinkList Lb,LinkList Lc){
           LNode *pa=La->next,*pb=Lb->next,*pc=Lc;
           while(pa && pb){
               if(pa->data<=pb->data){pc->next=pa;pc=pa;pa=pa->next;}
               else{pc->next=pb;pc=pb;pb=pb->next;}
           }
           pc->next = pa?pa:pb;     // 挂上剩余链
           free(La); free(Lb);
       }
    ```
    时间 O(m+n)，额外空间 O(1)。
3.  ```C
       int DelAllX(LinkList L,ELEMType x){
           LNode *pre=L,*p=L->next,*q; int cnt=0;
           while(p){
               if(p->data==x){ q=p; pre->next=p->next; p=p->next; free(q); cnt++; }
               else { pre=p; p=p->next; }
           }
           return cnt;
       }
    ```
    用 pre 跟踪前驱，避免删除后断链；时间 O(n)。

## 第三章 栈和队列 {#第三章-栈和队列}


### 3.1 考情导航 {#3-dot-1-考情导航}

-   **识记** ：栈、队列的定义与术语；顺序栈、链栈、循环队列、链队列的结构。
-   **领会** ：栈"后进先出"、队列"先进先出"的操作特征；"假溢出"成因与循环队列的解决思想。
-   **简单应用** ：出栈序列合法性判定、括号匹配、表达式求值、循环队列首尾指针与元素数计算。
-   **综合应用** ：栈与递归的关系、用栈实现非递归算法；队列在层次遍历中的应用。


### 3.2 知识点系统精讲 {#3-dot-2-知识点系统精讲}


#### 3.2.1 栈（Stack） {#3-dot-2-dot-1-栈-stack}

**定义** ：只允许在表的一端（ **栈顶 top** ）进行插入和删除的线性表，另一端称栈底 bottom。空栈中插入为入栈（压栈 push），删除为出栈（弹栈 pop）。特性 **LIFO（后进先出）** 。

**（1）顺序栈** ：用数组 + 栈顶指针 top 实现。两种常见约定（做题先看题目约定！）

| 约定                             | 空栈    | 栈满           | 入栈         | 出栈         |
|--------------------------------|-------|--------------|------------|------------|
| top 指向 **栈顶元素** （教材常用，初始 top=−1） | top==−1 | top==maxSize−1 | `S[++top]=x` | `x=S[top--]` |
| top 指向 **待放位置** （初始 top=0） | top==0  | top==maxSize   | `S[top++]=x` | `x=S[--top]` |

-   **上溢（overflow）** ：栈满仍入栈，是出错状态； **下溢（underflow）** ：空栈仍出栈，常作程序控制条件。
-   **共享栈** ：两个栈共享一维数组，栈底分别设在两端、栈顶向中间增长，仅当两栈顶相邻（top1+1==top2）时满。

**（2）链栈** ：用单链表实现， **栈顶设在表头** （头插入栈、删头出栈均 O(1)），一般不带头结点也可，不存在栈满问题（除非内存耗尽）。

**（3）栈的经典应用**

① **数制转换** ：N 转 r 进制——"除基取余、余数入栈、依次出栈"即得结果。
② **括号匹配** ：遇左括号入栈；遇右括号时栈空则不匹配，否则弹栈配对；扫描结束栈须为空。
③ **表达式求值** （重点）

-   中缀表达式：运算符在两操作数之间，人易读但需处理 **运算符优先级与括号** 。
-   后缀（逆波兰）表达式：运算符在操作数之后， **无需括号** 。
-   **中缀→后缀（调度场思想）** ：操作数直接输出；运算符与栈顶比较，栈顶优先级 **≥** 当前则弹出再压当前；左括号入栈，遇右括号弹到对应左括号为止。
-   **后缀求值** ：遇操作数入栈；遇运算符弹出两个数（ **先弹的是右操作数 b，后弹的是左操作数 a** ），计算 a op b 后结果入栈；栈中最后唯一元素即值。

④ **栈与递归** ：递归本质是系统用 **递归工作栈** 保存每层的实参、局部变量、返回地址。可用用户栈改写为非递归（如二叉树非递归遍历、深度优先搜索）。

**（4）出栈序列问题（必考小题）** ：入栈顺序固定为 1,2,…,n，元素可边入边出。判定一个出栈序列是否合法：对序列中任一元素，其后出现且比它小的元素必须 **递减排列** 。

-   n 个不同元素合法出栈序列总数为 **卡特兰数** Cₙ = C(2n,n)/(n+1)：n=3→5，n=4→14。


#### 3.2.2 队列（Queue） {#3-dot-2-dot-2-队列-queue}

**定义** ：只允许在表尾（队尾 rear）插入、在表头（队头 front）删除的线性表。特性 **FIFO（先进先出）** 。入队 enQueue、出队 deQueue。

**（1）顺序队列与"假溢出"** ：front、rear 只增不减，数组后端已满（rear==maxSize）而前端因出队空出大量单元——这种"有空闲位置却报满"称 **假溢出** 。

**（2）循环队列（重点，把数组看成首尾相接的环，模运算）**

教材采用 **牺牲一个存储单元** 区分队空/队满，设容量为 maxSize：

| 操作/状态 | 公式                                   |
|-------|--------------------------------------|
| 初始（空队） | front=rear=0                           |
| 入队     | `Q[rear]=x; rear=(rear+1)%maxSize;`    |
| 出队     | `x=Q[front]; front=(front+1)%maxSize;` |
| **队空** | `front==rear`                          |
| **队满** | `(rear+1)%maxSize==front`              |
| **元素个数** | `(rear-front+maxSize)%maxSize`         |

> 另一方案是另设 size 计数器或 tag 标志位，可不牺牲单元。

**（3）链队列** ：带头结点的单链表 + 队头、队尾双指针。入队链在 rear 后、出队删 front 后第一个；空队 `front==rear` （均指向头结点）。

**（4）队列应用** ：操作系统作业/进程调度、打印缓冲区、消息队列；数据结构中 **层次遍历（二叉树层序、图 BFS）** 必须借助队列。


#### 3.2.3 栈与队列对比 {#3-dot-2-dot-3-栈与队列对比}

| 维度   | 栈              | 队列           |
|------|----------------|--------------|
| 规则   | LIFO 后进先出   | FIFO 先进先出  |
| 操作端 | 只在栈顶        | 队尾入、队头出 |
| 顺序实现难点 | 上溢            | 假溢出 → 循环队列 |
| 典型应用 | 递归、括号匹配、表达式、DFS | 调度、缓冲、BFS/层序遍历 |

### 4.2 知识点系统精讲 {#4-dot-2-知识点系统精讲}


#### 4.2.1 数组的存储与地址计算 {#4-dot-2-dot-1-数组的存储与地址计算}

数组是类型相同、下标有序的数据元素集合， **一旦定义维数与上下界就不再变化** ，故一般只做存取、修改，不做插删。存储方式为 **顺序存储** ，分两种映像次序：

设二维数组 A[m][n]（m 行 n 列），每元素 L 字节，基址 LOC(0,0)，0 基下标：

| 映像方式                        | 元素 A[i][j] 地址                 |
|-----------------------------|-------------------------------|
| **行（以）序为主序** （C/Pascal 默认，先变列号） | LOC(i,j)=LOC(0,0)+ **(i·n+j)** ·L |
| **列（以）序为主序** （Fortran，先变行号） | LOC(i,j)=LOC(0,0)+ **(j·m+i)** ·L |

三维 A[m1][m2][m3] 行优先：LOC(i,j,k)=LOC(0,0,0)+(i·m2·m3+j·m3+k)·L。口诀： **"后面的下标变化最快"** 。


#### 4.2.2 特殊矩阵的压缩存储 {#4-dot-2-dot-2-特殊矩阵的压缩存储}

压缩原则：多个值相同的元素只存一个；零元素不分配空间。

**（1）对称矩阵（aᵢⱼ=aⱼᵢ）** ：只存下三角（含主对角线），n 阶矩阵压入长度 n(n+1)/2 的一维数组 sa[]。行优先（下标均 1 起）映射：

```text
下三角 i≥j：k = i(i−1)/2 + j − 1        （sa 0 基）
上三角 i<j：由对称性，k = j(j−1)/2 + i − 1
```

**（2）三角矩阵** ：上（下）三角为常数 c，除存下（上）三角 n(n+1)/2 个元素外，再用 **最后一个位置存常数 c** ，总长 n(n+1)/2+1。

**（3）对角矩阵（带状矩阵）** ：以三对角矩阵为例，非零元仅在主对角线及其上下各一条带（|i−j|≤1）。按行优先压入一维数组，0 基映射 **k=2i+j−1** （1 基下标时），总数 3n−2。


#### 4.2.3 稀疏矩阵 {#4-dot-2-dot-3-稀疏矩阵}

判定：非零元个数少且分布无规律。常用存储：

**（1）三元组顺序表** ：每个非零元记 `(行号 i, 列号 j, 值 v)` ，按行（或列）优先排列，另记总行数、列数、非零元个数。

-   **普通转置** ：按原三元组列号 col 从小到大扫描，每固定一列就扫全表取该列元素，时间 O(n·t)（n 列数、t 非零元数）。
-   **快速转置** ：预先统计每列非零元个数 `num[col]` 及其在新表中的起始位置 `cpot[col]` ，一趟定位，时间 O(n+t)。
    -   `cpot[0]=0; cpot[col]=cpot[col−1]+num[col−1]` 。

**（2）十字链表** ：每个非零元同时挂在"行链表"和"列链表"上，结点含 right（同行下一非零元）、down（同列下一非零元）两个指针，适合频繁插删的稀疏矩阵。


#### 4.2.4 广义表（列表 Lists） {#4-dot-2-dot-4-广义表-列表-lists}

**定义** ：n（n≥0）个元素 a₁,a₂,…,aₙ 的有限序列，元素既可以是 **原子** （不可再分），也可以是 **子表** 。记作 LS=(a₁,a₂,…,aₙ)。

| 术语       | 定义                                  |
|----------|-------------------------------------|
| 长度       | 广义表 **最外层** 元素个数（逗号数+1） |
| 深度       | 括号嵌套的 **最大层数** （原子深度 0，空表深度 1） |
| 表头 GetHead | 第一个元素 a₁（ **可以是原子或子表** ） |
| 表尾 GetTail | 除表头外其余元素组成的 **子表** （ **永远是表，必须带括号** ） |
| 空表       | ( )，长度 0、深度 1                   |

**经典运算规则（高频）** ：每次只剥最外层；表尾一定是表。

-   A=(a,(b,c),d)：Head(A)=a；Tail(A)=((b,c),d)；Head(Tail(A))=(b,c)；Head(Head(Tail(A)))=b。
-   递归表/再入表/共享表：表元素可以是自身或共享子表；纯表（树结构）→ 再入表（有向无环图）→ 递归表（有环图）。

**存储结构** ：头尾表示法（tag=0 原子 / tag=1 子表，hp 表头指针、tp 表尾指针）；扩展线性链表表示法（同层结点用 tp 链起来）。


#### 4.2.5 串（字符串） {#4-dot-2-dot-5-串-字符串}

**（1）基本概念** ：串是零个或多个字符组成的有限序列 S='a₁a₂…aₙ'；n 为长度，n=0 为 **空串** （''，不含任何字符）；由空格字符组成的串称 **空格串** （长度非 0）。 **子串** 是串中任意连续字符序列；主串包含子串；两串相等要求长度相同且对应字符全等。

**（2）模式匹配** ：在主串 S 中寻找模式串 T 的过程，找到返回位置，否则 0。

**① 朴素匹配算法 BF（Brute-Force）** ：主串指针 i、模式指针 j；字符相等则同时前进；失配时 **i 回退到 i−j+2、j 回到 1** ，重新比较。最坏时间 **O(n·m)** （n 主串长、m 模式长），优点是思路简单、无需预处理。

**② KMP 算法（重点）** ：失配后 **主串指针 i 不回溯** ，模式串按 next 数组滑动到恰当位置，j=next[j]，整体时间 **O(n+m)** 。

**next[j] 的含义** ：模式串前 j−1 个字符中，"最长相等真前缀与真后缀"长度 +1。教材（1 基）计算规则：

```text
next[1]=0；next[2]=1；
对 j>2：取最大的 k (1<k<j)，使 't₁…t_{k−1}' == 't_{j−k+1}…t_{j−1}'，则 next[j]=k；
        若不存在这样的 k，则 next[j]=1。
```

手工速算步骤：对每个位置 j，比较模式前缀与后缀的最长公共长度 L，next[j]=L+1。

**nextval（next 的改进，消除无意义比较）** ：

```text
nextval[1]=0；
若 T[j] == T[next[j]]，则 nextval[j]=nextval[next[j]]；
否则 nextval[j]=next[j]。
```

### 5.2 知识点系统精讲 {#5-dot-2-知识点系统精讲}


#### 5.2.1 树的基本概念 {#5-dot-2-dot-1-树的基本概念}

**定义（递归）** ：树是 n（n≥0）个结点的有限集；n=0 为空树；非空树有且仅有一个 **根 root** ，其余结点分成 m（m≥0）个互不相交的有限集，每个集合本身又是一棵子树。

| 术语     | 含义                          |
|--------|-----------------------------|
| 结点的度 | 结点拥有的子树数（孩子数）；树的度 = max{各结点度} |
| 叶子（终端结点） | 度为 0 的结点；分支结点（非终端）度&gt;0 |
| 孩子/双亲/兄弟 | 子树的根是该结点孩子；该结点是它们双亲；同双亲互为兄弟 |
| 层次     | 根为第 1 层，其孩子第 2 层，依次递推 |
| 深度（高度） | 树中结点的最大层次            |
| 有序树/无序树 | 子树从左到右有次序不能互换为有序树 |
| 森林     | m（m≥0）棵互不相交的树的集合；一棵树删根即森林 |

**树的常用性质** ：① 结点数 = 总度数 + 1（每条边贡献 1 个度，n 个结点 n−1 条边）；② 度为 m 的树第 i 层至多 m^(i−1) 个结点。

**三种存储表示** ：双亲表示法（数组+parent 下标，找双亲 O(1)、找孩子要遍历）、孩子表示法（每个结点挂孩子链表）、 **孩子兄弟表示法（二叉树表示法）** ：firstchild + nextsibling 两指针，是树与二叉树转换的基础。


#### 5.2.2 二叉树（Binary Tree） {#5-dot-2-dot-2-二叉树-binary-tree}

**定义** ：每个结点度不超过 2，且子树有 **左右之分、次序不能颠倒** 。五种基本形态：空、仅根、根+左、根+右、根+左右。

**五大性质（必背，层从 1 计）**

1.  第 i 层至多 **2^(i−1)** 个结点；
2.  深度为 k 的二叉树至多 **2^k−1** 个结点；
3.  叶子数 n₀ 与度为 2 结点数 n₂ 满足 **n₀ = n₂ + 1** （推导：n=n₀+n₁+n₂，n−1=0·n₀+1·n₁+2·n₂，两式相减）；
4.  具有 n 个结点的 **完全二叉树** 深度为 **⌊log₂n⌋+1** ；
5.  完全二叉树按层序编号（根为 1）：结点 i 的左孩子 **2i** 、右孩子 **2i+1** 、双亲 **⌊i/2⌋** ；i≤⌊n/2⌋ 为分支结点，否则为叶子。

**两种特殊二叉树**

-   **满二叉树** ：深度 k 且恰有 2^k−1 个结点，每层都满；所有叶子在最底层，分支结点度都为 2。
-   **完全二叉树** ：深度 k、n 个结点，当且仅当每个结点都与深度 k 的满二叉树中编号 1..n 的结点一一对应。特点：叶子只可能在最下两层；若度为 1 的结点存在则 **至多一个且只有左孩子** ；编号 i&lt;⌊n/2⌋ 的结点必有两个孩子。


#### 5.2.3 二叉树的存储结构 {#5-dot-2-dot-3-二叉树的存储结构}

-   **顺序存储** ：用一组连续单元按 **完全二叉树层序编号** 存放；适合完全二叉树（无浪费），一般二叉树尤其单支树会造成巨大空间浪费（最坏 n 结点要 2ⁿ−1 空间）。
-   **二叉链表** ： `lchild | data | rchild` 。n 个结点有 **n+1 个空指针域** （推导：2n 个指针域，n−1 个指向孩子，余 n+1 为空）——这是线索化的空间来源。
-   **三叉链表** ：再加 parent 指针，便于找双亲。

<!--listend-->

```C
typedef struct BiTNode {
    ELEMType data;
    struct BiTNode *lchild,*rchild;
} BiTNode, *BiTree;
```


#### 5.2.4 二叉树的遍历（核心中的核心） {#5-dot-2-dot-4-二叉树的遍历-核心中的核心}

**（1）三种递归遍历（以访问根的先后命名，左右顺序恒为先左后右）**

| 遍历   | 顺序                    | 典型用途           |
|------|-----------------------|----------------|
| 先序 DLR | 根→左子树→右子树        | 复制树、前缀表达式、树的深度 |
| 中序 LDR | 左→根→右                | BST 得有序序列、中缀表达式 |
| 后序 LRD | 左→右→根                | 求树高、释放树、后缀表达式、目录大小 |
| 层序   | 自上而下、同层自左向右（ **队列** 实现） | 宽度、按层处理     |

```C
void PreOrder(BiTree T){
    if(T){ visit(T); PreOrder(T->lchild); PreOrder(T->rchild); }
}
```

**（2）非递归遍历（用栈）**

-   先序：沿左链一路访问并入栈，走不动时弹栈转向右子树，循环。
-   中序：沿左链一路 **入栈不访问** ，走不动时弹栈并访问，再转向右子树。
-   后序：最复杂。常用 **双栈法** 或给结点加访问标记（第一次入栈、第二次出栈才访问）；也可用"根右左"先序再整体逆序得到后序。

**（3）由遍历序列还原二叉树（必考）**

-   **先序 + 中序** ：先序首元素是根，在中序中切分左右子树，递归构造。
-   **后序 + 中序** ：后序末元素是根，同样切分。
-   **层序 + 中序** 也可唯一确定。
-   仅给先序+后序 **不能** 唯一确定（左右子树无法区分）。
-   对 BST，只要知道其中序（即排序结果）+任一其他序列即可还原。


#### 5.2.5 线索二叉树 {#5-dot-2-dot-5-线索二叉树}

**动机** ：n+1 个空链域被浪费。规定 ltag/rtag 为 0 时指针指向孩子，为 1 时指向 **前驱/后继（线索）** ：

```text
ltag=0 lchild 指左孩子；ltag=1 lchild 指遍历前驱
rtag=0 rchild 指右孩子；rtag=1 rchild 指遍历后继
```

分先序/中序/后序线索二叉树。 **中序线索二叉树** 最常用：在中序序列中，结点的前驱是其左子树最右下结点，后继是其右子树最左下结点。线索化实质是遍历过程中用 pre 指针记录上一访问结点、把空指针改成线索。加 **头结点** 可使首尾线索闭环。


#### 5.2.6 树、森林与二叉树的转换（左孩子右兄弟） {#5-dot-2-dot-6-树-森林与二叉树的转换-左孩子右兄弟}

-   **树→二叉树** ：兄弟连线；每个结点只保留与第一个孩子的连线，其余删去；顺时针旋转 45°。口诀" **左孩子，右兄弟** "。
-   **森林→二叉树** ：各树先转二叉树；后一棵树的根作为前一棵树根的右孩子依次相连。
-   **二叉树→树/森林** ：逆操作，左孩子的右链全部"拆开"变兄弟。
-   **遍历对应关系（必记）**

| 树   | 森林 | 对应二叉树 |
|-----|----|-------|
| 先根遍历 | 先序遍历 | 先序遍历 |
| 后根遍历 | 中序遍历 | 中序遍历 |


#### 5.2.7 哈夫曼（Huffman）树与哈夫曼编码 {#5-dot-2-dot-7-哈夫曼-huffman-树与哈夫曼编码}

**术语** ：路径（分支序列）、路径长度（边数）、树的路径长度 PL（根到各结点路径长度之和）、 **带权路径长度 WPL=Σ wₖ·lₖ** （lₖ 为根到叶 k 的路径长度）。

**哈夫曼树（最优二叉树）** ：n 个带权叶子构成的所有二叉树中 **WPL 最小** 的二叉树。

**构造步骤** ：① n 个权值看成 n 棵单结点树组成森林；② 取两个 **权值最小** 的树作左右子树合成新树，新树根权=两子树权之和；③ 从森林删除这两棵、加入新树；④ 重复到只剩一棵树。

**重要结论**

1.  n 个叶子的哈夫曼树总结点数 **2n−1** ，且 **没有度为 1 的结点** ；
2.  哈夫曼树不唯一（左右孩子可互换）但最小 WPL 唯一；
3.  **哈夫曼编码** ：左分支标 0、右分支标 1，根到叶子路径上的 0/1 序列即该字符编码；它是 **前缀码（任一编码都不是另一编码的前缀）** ，保证无二义性；频率越高的字符编码越短，使总码长最小。


#### 5.2.8 堆与优先队列（为第 7 章堆排序奠基） {#5-dot-2-dot-8-堆与优先队列-为第-7-章堆排序奠基}

-   **堆** ：n 个元素序列 K₁..Kₙ，满足 Kᵢ≥K₂ᵢ 且 Kᵢ≥K₂ᵢ₊₁（ **大根堆/最大堆** ，父≥子）或 Kᵢ≤…（小根堆）。堆对应一棵 **完全二叉树** ：大根堆堆顶是全局最大值。
-   **建堆（自下向上筛选）** ：从最后一个分支结点 ⌊n/2⌋ 起，逆层序逐个"向下筛选"ShiftDown（与较大孩子比较，小则交换，直到满足堆性质）。
-   **插入** ：新元素放末尾，再"向上筛选"（与父比，违例则交换上浮）。
-   **删除堆顶** ：末元素移到堆顶，堆规模 −1，再向下筛选。优先队列：出队取堆顶、入队即堆插入。

### 6.2 知识点系统精讲 {#6-dot-2-知识点系统精讲}


#### 6.2.1 图的基本概念 {#6-dot-2-dot-1-图的基本概念}

**定义** ：图 G 由 **顶点集 V** 和 **边集 E** 组成，记 G=(V,E)。

| 术语    | 含义                                                                         |
|-------|----------------------------------------------------------------------------|
| 有向图  | 边是顶点有序对 ⟨v,w⟩（称 **弧** ，v 弧尾/起点，w 弧头/终点）                 |
| 无向图  | 边是无序对 (v,w)                                                             |
| 完全图  | 无向完全图边数 **n(n−1)/2** ；有向完全图弧数 **n(n−1)**                      |
| 稀疏图/稠密图 | 边数较少/较多（e&lt;nlog n 常视为稀疏）                                      |
| 网（网络） | 边（弧）上带权值的图                                                         |
| 度      | 无向：与 v 关联边数 TD(v)；有向分 **入度 ID** （以 v 为弧头）与 **出度 OD** （以 v 为弧尾）， **TD=ID+OD** |
| 握手定理 | 无向图所有顶点度数之和 = **2e** （每条边贡献 2 度）；有向图 ΣID=ΣOD=e        |
| 路径/路径长度 | 顶点序列；长度为路径上边（弧）数，网中为权值之和                             |
| 回路（环） | 第一个与最后一个顶点相同的路径；简单路径顶点不重复                           |
| 连通    | 无向图中两顶点间有路径；任两点都连通为 **连通图** ，极大连通子图为 **连通分量** |
| 强连通  | 有向图中任两点 **互相可达** ；极大强连通子图为强连通分量                     |
| 生成树  | 连通图的极小连通子图，含全部 n 顶点且恰 **n−1 条边** ；少一边不连通、多一边成环 |


#### 6.2.2 图的存储结构 {#6-dot-2-dot-2-图的存储结构}

**（1）邻接矩阵（数组表示法）** ：用 n×n 矩阵 A 表示，无权图 A[i][j]=1 当且仅当有边（弧）；网中存权值，无边存 ∞，对角线 0。

-   无向图矩阵 **对称** ，可压缩；第 i 行（列）非零元个数 = 顶点 i 的度。
-   有向图： **第 i 行非零数 = 出度 OD(i)，第 i 列非零数 = 入度 ID(i)** 。
-   空间 **O(n²)** ，与边数无关；判定两顶点是否相邻 O(1)，适合稠密图。

**（2）邻接表** ：顶点表（每个顶点一个边链表头指针）+ 边（弧）结点链表。

-   无向图每条边在两个边表中各出现一次，共 2e 个边结点；有向图（出边表）e 个弧结点，求入度需建 **逆邻接表** 。
-   空间 **O(n+e)** ，适合稀疏图；找邻接点高效，判定任意两点是否相邻最坏 O(n)。

**（3）十字链表** ：有向图专用，弧结点同时串入"以同一顶点为尾"和"以同一顶点为头"的两条链（tailvex/headvex/hlink/tlink），同时方便求入度、出度。

**（4）邻接多重表** ：无向图专用，每条边只用一个结点却能同时挂在两个顶点的链上，方便标记/删除边。


#### 6.2.3 图的遍历 {#6-dot-2-dot-3-图的遍历}

**（1）深度优先搜索 DFS（类似树先根，借助栈/递归）** ：访问 v→置已访问标记→依次沿未访问邻接点递归深入，走不通再回溯。

-   邻接表： **O(n+e)** ；邻接矩阵： **O(n²)** ；需要 visited[] 数组与（递归）工作栈 O(n)。
-   DFS 生成树：递归经过的边构成；非连通图得到 DFS 生成森林。

**（2）广度优先搜索 BFS（类似树层序，借助队列）** ：访问 v 入队；出队一个顶点就把它所有未访问邻接点访问并入队，逐层外扩。

-   复杂度同 DFS；BFS 生成树中从根到各顶点的路径边数最少（ **无权图最短路** ）。
-   邻接点的访问次序不同，生成树/遍历序列不唯一（但按邻接表固定次序时唯一）。


#### 6.2.4 最小生成树 MST（连通无向网，总权值最小的生成树） {#6-dot-2-dot-4-最小生成树-mst-连通无向网-总权值最小的生成树}

**（1）Prim 算法（从顶点生长，"加点法"）**

-   过程：任取一顶点加入集合 U；每次在 **一端∈U、一端∈V−U** 的边中取权最小者，把对应顶点并入 U；直到 U=V。
-   时间 **O(n²)** ，与边数无关， **适合稠密图** ；可用最小堆优化到 O(elog n)。

**（2）Kruskal 算法（从边生长，"加边法"）**

-   过程：所有边按权升序排列；依次考察，若该边两端点 **分属两个不同连通分量** （用并查集判定）则选中并合并分量，否则舍弃（会成环）；选够 n−1 条边结束。
-   时间主要花在排序 **O(e log e)** ， **适合稀疏图** 。
-   两算法对同一网所得 MST 总权值相同；当存在等权边时具体树形可能不同。


#### 6.2.5 最短路径 {#6-dot-2-dot-5-最短路径}

**（1）Dijkstra 单源最短路径（一个源点到其余各点）**

-   思想（贪心）：集合 S 存放已确定最短路径的顶点，dist[] 记录当前已知最短距离；每轮选 S 外 dist 最小的顶点 v 并入 S，并用 v **松弛** 其余顶点： `dist[w]=min(dist[w], dist[v]+weight(v,w))` 。
-   时间 O(n²)； **不允许负权边** （教材范围）。

**（2）Floyd 全源最短路径（每对顶点之间）**

-   动态规划递推： `A⁽ᵏ⁾[i][j]=min(A⁽ᵏ⁻¹⁾[i][j], A⁽ᵏ⁻¹⁾[i][k]+A⁽ᵏ⁻¹⁾[k][j])` ，k 从 0 到 n−1 依次作"中转点"。
-   时间 **O(n³)** 、空间 O(n²)，允许负权但不许负环；写法简洁、常数小。


#### 6.2.6 有向无环图（DAG）及其应用 {#6-dot-2-dot-6-有向无环图-dag-及其应用}

**（1）拓扑排序（AOV 网：顶点表示活动、弧表示先后制约）**

-   步骤：① 统计各顶点 **入度** ；② 选入度为 0 的顶点输出并删除其所有出边（邻接点入度 −1）；③ 重复直到输出全部 n 个顶点。
-   若最终输出顶点数 &lt; n，说明图中 **存在环（有向环）** ，工程不可行。
-   拓扑序列一般不唯一；用栈/队列存零入度顶点，时间 O(n+e)。

**（2）关键路径（AOE 网：边表示活动、顶点表示事件，带权有向无环图，单源单汇）**

| 量             | 含义与求法                                  |
|---------------|----------------------------------------|
| ve(k) 事件最早发生时间 | 从源点顺拓扑方向：ve(j)=max{ve(i)+权(i,j)}，源点 ve=0 |
| vl(k) 事件最迟发生时间 | 从汇点逆拓扑：vl(i)=min{vl(j)−权(i,j)}，汇点 vl=ve |
| e(aₖ) 活动最早开始时间 | 活动 aₖ=⟨i,j⟩：e=ve(i)                      |
| l(aₖ) 活动最迟开始时间 | l=vl(j)−权(i,j)                             |
| **关键活动/关键路径** | **l−e=0** 的活动为关键活动；由关键活动串联成的路径为关键路径，长度=最短工期 |

-   关键路径长度等于汇点的 ve； **只有加快关键活动** （且缩短后仍为关键活动）才能缩短工期；关键路径可能不止一条，需同时缩短所有关键路径上的活动。

## 第七章 内部排序 {#第七章-内部排序}


### 7.1 考情导航 {#7-dot-1-考情导航}

-   **识记** ：排序、稳定性、内/外排序、逆序对的概念；八类排序算法的基本思想。
-   **领会** ：每种排序的比较/移动次数、时空复杂度、稳定性与适用条件。
-   **简单应用** ：手工写出各排序每一趟结果；由一趟结果反推排序方法；建堆、整堆、快速划分过程。
-   **综合应用** ：排序算法改进、排序方法选择、计数类/逆序对类算法设计。


### 7.2 知识点系统精讲 {#7-dot-2-知识点系统精讲}


#### 7.2.1 基本概念 {#7-dot-2-dot-1-基本概念}

-   **排序** ：把一组记录按关键字 **非递减（升序）或非递增（降序）** 重新排列。
-   **内部排序** ：数据全部在内存中完成； **外部排序** ：数据量大、需内外存交换（本课程重点是内排序）。
-   **稳定性** ：关键字相等的两记录 rᵢ、rⱼ（排序前 rᵢ 在 rⱼ 前），排序后 rᵢ 仍在 rⱼ 前 → **稳定** ，否则不稳定。
-   **逆序对** ：两记录关键字大小次序与其相对次序不一致；排序过程就是不断消除逆序对的过程。
-   主要操作： **关键字比较 + 记录移动（交换）** ；时间分最好、最坏、平均三种；空间看辅助存储。
-   比较类排序的理论下界 **Ω(n log n)** （基于比较决策树）。


#### 7.2.2 插入排序 {#7-dot-2-dot-2-插入排序}

**（1）直接插入排序** ：把序列分成有序前段与无序后段；每趟取无序段第一个，在有序段中自右向左边比较边后移，落入正确位置。共 n−1 趟。

| 项      | 结论                       |
|--------|--------------------------|
| 最好（已有序） | 比较 n−1 次、移动 0 次， **O(n)** |
| 最坏（逆序） | 比较/移动约 n(n−1)/2， **O(n²)** |
| 平均    | **O(n²)**                  |
| 空间    | O(1)（一个 temp）          |
| 稳定性  | **稳定** （相等不移动）    |

折半插入排序：用折半查找定位插入位置，比较次数降为 O(n log n)，但移动次数仍 O(n²)，时间仍 O(n²)，稳定。

**（2）希尔排序（缩小增量排序）** ：先取较大增量 d，把"相隔 d"的元素分组做组内直接插入；逐趟缩小 d， **最后一趟 d=1 做整体直接插入** 。增量序列无统一最优方案（互不为倍数、取奇数效果较好）。

-   时间约 O(n^1.3)（依赖增量序列，介于 O(n log n) 与 O(n²)）；空间 O(1)； **不稳定** （大步长交换改变相等元素相对次序）。
-   反推题：一趟希尔排序后，每个"相隔 d"的子序列内部必有序，据此用排除法确定 d。


#### 7.2.3 交换排序 {#7-dot-2-dot-3-交换排序}

**（1）起泡（冒泡）排序** ：从前往后两两比较相邻元素，逆序则交换，一趟把 **最大值"冒"到末尾** ；下趟范围减 1。共 n−1 趟，比较总次数固定 n(n−1)/2。

| 项                          | 结论                    |
|----------------------------|-----------------------|
| 基本版比较次数              | 任何初始情况都是 n(n−1)/2，O(n²) |
| 改进版（设交换标志 flag / 右边界 right） | 已有序时只走一趟， **最好 O(n)** |
| 平均/最坏                   | O(n²)；空间 O(1)        |
| 稳定性                      | **稳定** （相邻比较、相等不交换） |

**（2）快速排序** ：基于 **分治** 。选枢轴 pivot（教材取首元素并暂置末尾），一趟 **划分 partition** 使枢轴左侧都≤它、右侧都≥它，枢轴落到最终位置；再对左右两段递归。

-   划分：left 从左找第一个 &gt; pivot，right 从右找第一个 &lt; pivot，交换；交错后枢轴归位。
-   **每趟至少一个元素（枢轴）到达最终位置** 。

| 项    | 结论                                    |
|------|---------------------------------------|
| 最好/平均 | **O(n log n)** （每次划分较均衡，递归树高 log n） |
| 最坏  | **O(n²)** （已有序/逆序且取首元素为枢轴，每次分出空段，n−1 趟） |
| 空间  | 递归栈 O(log n)~ **O(n)**               |
| 稳定性 | **不稳定**                              |
| 改进  | 三元取中选枢轴；小段改用直接插入；非递归化 |


#### 7.2.4 选择排序 {#7-dot-2-dot-4-选择排序}

**（1）简单选择排序** ：第 i 趟在剩余 a[i..n−1] 中找最小关键字，与 a[i] 交换。共 n−1 趟。

-   **比较次数与初始状态无关** ，恒为 n(n−1)/2，O(n²)； **每趟至多交换 1 次** ，交换次数 0~n−1；空间 O(1)； **不稳定** （跨位置交换）。

**（2）堆排序** ：利用堆。大根堆堆顶为最大值。过程：① 自下而上 **建初始堆** ；② 堆顶与当前堆最后一个元素交换（输出到最终位置），堆规模 −1，对新堆顶 **向下筛选整堆** ；③ 重复 n−1 次。大根堆得升序、小根堆得降序。

| 项       | 结论                          |
|---------|-----------------------------|
| 建堆     | 从 ⌊n/2⌋ 起逐个 ShiftDown，O(n) |
| 最好/平均/最坏 | **均为 O(n log n)** ，不受初始有序性影响 |
| 空间     | **O(1)**                      |
| 稳定性   | **不稳定**                    |
| 适用     | 要求最坏情况也有保证、求 Top-k（只需建 k 规模堆） |


#### 7.2.5 归并排序（二路归并） {#7-dot-2-dot-5-归并排序-二路归并}

-   **归并 merge** ：把两个相邻有序段用双指针合并成一个有序段，需等长辅助数组，合并 O(n)。
-   非递归：长度 1 的有序段两两归并 → 长度 2 → 4…直到整体有序；递归：等分 → 各自排序 → 归并。
-   时间： **最好=平均=最坏=O(n log n)** （二分 log n 层，每层总扫描 n）；空间 **O(n)** （辅助数组）； **稳定** （合并时相等取左段）。


#### 7.2.6 分配排序 {#7-dot-2-dot-6-分配排序}

**（1）盒子排序（计数排序雏形）** ：以值域大小开 count 数组，扫描计数后按序输出。值域为 k 时时间 O(n+k)、空间 O(k)；要求关键字能映射为小范围非负整数。

**（2）基数排序** ：关键字拆成 d 个子关键字（如十进制的个位、十位），借助 r 个"盒子（桶/链队列）"， **从最低位到最高位（LSD）逐趟"分配—收集"** ，共 d 趟。

-   时间 **O(d·(n+r))≈O(dn)** （d、r 固定时线性）；空间 O(n+r)； **稳定** （稳定性是多趟分配收集结果正确的前提，绝不能用不稳定操作）。


#### 7.2.7 八种内部排序总对比（教材表 7-1，必背） {#7-dot-2-dot-7-八种内部排序总对比-教材表-7-1-必背}

| 排序方法 | 最好       | 平均        | 最坏       | 辅助空间      | 稳定性 |
|------|----------|-----------|----------|-----------|-----|
| 直接插入排序 | O(n)       | O(n²)       | O(n²)      | O(1)          | **稳定** |
| 起泡排序 | O(n)       | O(n²)       | O(n²)      | O(1)          | **稳定** |
| 简单选择排序 | O(n²)      | O(n²)       | O(n²)      | O(1)          | 不稳定 |
| 希尔排序 | —          | O(n^1.3) 量级 | —          | O(1)          | 不稳定 |
| 快速排序 | O(n log n) | O(n log n)  | O(n²)      | O(log n)~O(n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n)  | O(n log n) | O(n)          | **稳定** |
| 堆排序 | O(n log n) | O(n log n)  | O(n log n) | O(1)          | 不稳定 |
| 基数排序 | O(dn)      | O(dn)       | O(dn)      | O(n+r)        | **稳定** |

**高频结论**

1.  **每趟结束至少一个元素到达最终位置** ：起泡、选择、快速、堆排序； **不能保证** 的是直接插入（整体看也逐步增长有序段，但单趟不保证某元素最终定位——严格说插入排序每趟把当前元素放到"当前有序段"的位置而非最终位置）、希尔、归并、基数。
2.  平均最快：快速排序；最坏有保证：堆排序、归并排序；稳定且 O(n log n)： **只有归并排序** ；基本有序或 n 很小：直接插入最佳。
3.  已有序时反而最慢：取首元素为枢轴的快速排序（O(n²)）；已有序时最快：改进起泡、直接插入（O(n)）。
4.  不稳定四兄弟： **希尔、快速、简单选择、堆** ；稳定：插入、起泡、归并、基数。

       void BInsertSort(myRcd *R){

               ELEMType t=R->data[i];

               while(low<=high){           // 折半定位插入位置

    ```C
       void Flag012(int a[],int n){   // 荷兰国旗：lo 左侧全0，hi 右侧全2，mid 扫描
           int lo=0,mid=0,hi=n-1,t;
           while(mid<=hi){
               if(a[mid]==0){t=a[lo];a[lo]=a[mid];a[mid]=t;lo++;mid++;}
               else if(a[mid]==2){t=a[hi];a[hi]=a[mid];a[mid]=t;hi--;}
               else mid++;
           }
       }
    ```

       long cnt=0;
       void merge(int a[],int tmp[],int l,int m,int r){
           int i=l,j=m+1,k=l;
           while(i<=m && j<=r){
               if(a[i]<=a[j]) tmp[k++]=a[i++];
               else { tmp[k++]=a[j++]; cnt += m-i+1; } // a[j] 与左段剩余均成逆序
           }
           while(i<=m) tmp[k++]=a[i++];
           while(j<=r) tmp[k++]=a[j++];
           for(i=l;i<=r;i++) a[i]=tmp[i];
       }
    ```
    递归二分 + 合并，时间 O(n log n)，空间 O(n)。

### 8.2 知识点系统精讲 {#8-dot-2-知识点系统精讲}


#### 8.2.1 基本概念与平均查找长度 {#8-dot-2-dot-1-基本概念与平均查找长度}

-   **查找表** ：由同一类型记录构成的集合； **关键字** 分主关键字（唯一标识）与次关键字。
-   结果分 **成功查找** 与 **不成功（失败）查找** ；分静态查找表（只查不改）与动态查找表（查找中可插入/删除）。
-   **平均查找长度 ASL = Σᵢ₌₁ⁿ pᵢcᵢ** ：pᵢ 为查找第 i 个记录的概率，cᵢ 为找到它所需的比较次数。等概率时 pᵢ=1/n。


#### 8.2.2 顺序表的三种查找 {#8-dot-2-dot-2-顺序表的三种查找}

**（1）顺序查找（线性查找）** ：从头到尾逐个比较，对存储结构与是否有序无要求（顺序、链式均可）。

-   等概率成功 **ASL=(n+1)/2** ，失败比较 n 次，时间 **O(n)** ，空间 O(1)。
-   **哨兵技巧** ：0 号单元存目标，循环可省去"是否越界"判断，效率更高。
-   自组织线性表：按查找频率从高到低排列可降低平均比较次数。

**（2）折半查找（二分查找）** ： **仅适用于有序的顺序表** （链表无法 O(1) 取中点，不适用）。

```C
low=0; high=n-1;
while(low<=high){
    mid=(low+high)/2;          // 向下取整，全书统一
    if(R[mid]==target) return mid;
    else if(target<R[mid]) high=mid-1;
    else low=mid+1;
}
return -1;
```

-   每比较一次区间约减半，时间 **O(log₂n)** ；判定树为平衡（近似满）二叉树，比较次数=根到该结点路径结点数， **最多 ⌊log₂n⌋+1 次** 。
-   n=2^h−1 时 ASL 成功 ≈ log₂(n+1)−1；取整方式（上取整/下取整）不同会得到两棵不同判定树。

**（3）索引顺序查找（分块查找）** ：表分若干块， **块间整体有序、块内可无序** ；每块抽最大关键字+起始位置建 **有序索引表** 。先查索引表（可折半）定块，再块内顺序查找。

-   设 n 个记录、b 块、每块 s 条，索引与块内均顺序查找： **ASL=(b+1)/2+(s+1)/2** ；当 **s=√n** 时 ASL 最小（≈√n+1）。


#### 8.2.3 二叉查找树 BST（二叉搜索树） {#8-dot-2-dot-3-二叉查找树-bst-二叉搜索树}

**定义** ：空树，或满足：左子树所有关键字 &lt; 根 &lt; 右子树所有关键字，且左右子树本身也是 BST。 **中序遍历 BST 得到递增有序序列** 。

-   **查找** ：从根比较，小则向左、大则向右，命中成功、遇空失败，比较次数不超过树高。
-   **插入** ：新结点总是作为 **叶子** 插在查找失败的空指针处；从空树按序列插入即生成 BST（插入次序不同，树形不同）。
-   **删除分三种情况** ：
    1.  删叶子：直接删；
    2.  删度为 1 结点：用其唯一孩子顶替它；
    3.  删度为 2 结点：用其 **中序直接前驱（左子树最大者，无右孩子）或直接后继（右子树最小者，无左孩子）** 顶替，再删该前驱/后继（转化为情形 1 或 2）。
-   **性能** ：最好/随机情况下树高 O(log n)，平均 ASL≈O(log n)；最坏（关键字有序插入）退化为单支树，高 n，ASL=(n+1)/2， **O(n)** 。


#### 8.2.4 平衡二叉树（AVL 树） {#8-dot-2-dot-4-平衡二叉树-avl-树}

-   **平衡因子 BF = 左子树高度 − 右子树高度** ，AVL 树任一结点 **BF∈{−1,0,1}** 。
-   高度为 h 的 AVL 树 **最少结点数** N(h)：N(0)=0，N(1)=1， **N(h)=N(h−1)+N(h−2)+1** （h=2→2，h=3→4，h=4→7，h=5→12）。
-   插入新结点（必为叶子）后，找 **距新结点最近的失平衡结点 v** ，按新结点相对 v 的位置分四类旋转：

| 类型 | 位置关系     | 调整方法                |
|----|----------|---------------------|
| LL | 插在 v 左孩子的左子树 | **右旋一次** （以左孩子为轴上提） |
| RR | 插在 v 右孩子的右子树 | **左旋一次**            |
| LR | 插在 v 左孩子的右子树 | **先左旋（左孩子为根）再右旋（v 为根）** |
| RL | 插在 v 右孩子的左子树 | **先右旋再左旋**        |

-   一次插入最多一次调整即可恢复平衡；查找/插入/删除均 **O(log n)** 。


#### 8.2.5 B 树（多路平衡查找树，用于外存索引） {#8-dot-2-dot-5-b-树-多路平衡查找树-用于外存索引}

**m 阶 B 树性质（必背）**

1.  每个结点至多 **m 棵子树、m−1 个关键字** ；
2.  **根结点** 若非叶则 **至少 2 棵子树** （至少 1 个关键字）；
3.  **非根结点** 至少 ⌈m/2⌉ 棵子树、 **⌈m/2⌉−1 个关键字** ；
4.  所有 **叶结点（外部结点/失败结点）在同一层** （绝对平衡）；
5.  结点内关键字递增排列，n 个关键字带 n+1 个指针，指针 Aᵢ 所指子树关键字介于 Kᵢ 与 Kᵢ₊₁ 之间。

6.  3 阶 B 树 = 2-3 树（结点 1~2 个关键字、2~3 棵子树）。
7.  **插入** ：在最底层非叶结点插入；关键字数达到 m（超限）则 **分裂** ——左右各留合法数目、 **中间关键字上提** 到父结点；递归上提，根分裂则树高 +1（B 树长高的唯一途径）。
8.  查找 = 结点内顺序/折半查找 + 沿指针下降，比较次数主要取决于树高（O(logₘn) 层）。


#### 8.2.6 哈希表（散列表）及其查找 {#8-dot-2-dot-6-哈希表-散列表-及其查找}

**（1）思想** ：由关键字通过 **哈希函数 H(key)** 直接计算存储地址 H(key)=addr，理想情况下无需比较。不同关键字映射到同一地址称 **冲突** ，这些关键字互称 **同义词** 。

**（2）哈希函数构造原则** ：计算简单、分布均匀。常用方法：

| 方法      | 公式/思想                                   |
|---------|-----------------------------------------|
| 直接定址法 | H(key)=key 或 a·key+b， **无冲突** ，适合连续分布关键字 |
| 平方取中法 | key² 后取中间若干位（每一位都影响结果）     |
| 折叠法    | 分段叠加、舍去进位，适合长关键字            |
| 基数转换法 | 先按另一进制看待再转回、取位                |
| **除留余数法** | **H(key)=key mod p，p 取不大于表长 m 的最大素数** （最常用） |

**（3）处理冲突的方法**

① **开放地址法（闭哈希）** ：冲突后按探测序列找下一空槽，Hi=(H(key)+dᵢ) mod m。

-   **线性探测** ：dᵢ=1,2,3,…（d<sub>i+1</sub>=(dᵢ+1) mod m）。简单，但会产生 **基本聚集（堆积）** 。
-   **二次（平方）探测** ：dᵢ=1²,−1²,2²,−2²,…，跳跃式探测，减轻聚集（ **二级聚集** ）；表长为素数且至少半空时必能找到空位。
-   伪随机探测：存放与查找必须用同一随机序列。

② **链地址法（开哈希）** ：每个地址挂一个同义词单链表，冲突记录挂入同一链表。插入删除方便、无聚集，α 可 &gt;1。

③ 桶式哈希：分桶+槽+溢出桶。

**（4）哈希表查找与 ASL**

-   查找路径与插入时的探测序列完全一致； **比较次数 = 该关键字插入时的探测次数** 。
-   **装填因子 α = 表中记录数 n / 表长 m** ：α 越大越易冲突，ASL 只与 α 有关、与 n 无关。
-   等概率下：
    -   **ASL 成功** = 各关键字比较次数之和 / 关键字个数；
    -   **ASL 失败** = 从每个哈希基地址出发、走到第一个空槽为止的比较次数的平均值（线性探测要沿探测链一直走到空槽）。
-   经典理论值（了解）：线性探测成功 ≈ (1+1/(1−α))/2；链地址成功 ≈ 1+α/2。
-   **删除** ：不能直接置空（会断掉后续同义词的探测链），应设"删除标记"；哈希法 **不适合范围查找与排序输出** 。


#### 8.2.7 查找方法总对比 {#8-dot-2-dot-7-查找方法总对比}

| 方法 | 适用结构 | 查找时间          | 插入删除    | 特点    |
|----|------|---------------|---------|-------|
| 顺序查找 | 任意表 | O(n)              | —           | 无前提、最慢 |
| 折半查找 | 有序顺序表 | O(log n)          | 插删需移动 O(n) | 查找快、变动难 |
| 分块查找 | 块间有序 | 约 O(√n)          | 块内插删较易 | 折中方案 |
| BST  | 二叉链表 | 均 O(log n)，坏 O(n) | O(log n) 方便 | 中序有序 |
| AVL  | 平衡 BST | 稳定 O(log n)     | 旋转维护平衡 | 最坏也有保证 |
| B 树 | m 路平衡树 | O(logₘn)          | 分裂/合并   | 面向外存、矮胖 |
| 哈希 | 数组+散列 | 均 O(1)           | 平均 O(1)   | 不支持范围查找 |

           return TRUE;
       }
    ```

### 四、算法阅读题 {#四-算法阅读题}

(1) 遍历带头结点单链表，累加所有结点数据 s 并计数 c，返回 **链表所有整数的平均值** （s/c）。
(2) 每个结点访问一次， **时间 O(n)** ；只用 s、c、p 三个辅助变量， **空间 O(1)** 。
(3) 空表时 c=0，函数返回 0；但"平均值为 0"与"表为空"语义混淆（非空表平均值也可能为 0）。改进：让函数返回状态标志（如 int 指针参数带出平均值，空表返回 ERROR；或用引用参数 `int *avg` ，函数返回 TRUE/FALSE 表示是否有数据）。


### 五、算法设计题 {#五-算法设计题}

(1) 分治递归：空树 0，否则 1+左子树结点数+右子树结点数。

```C
int NodeCount(BiTree T){
    if(T==NULL) return 0;
    return 1 + NodeCount(T->lchild) + NodeCount(T->rchild);
}
```

评分：边界 2 分；递归式 4 分。

(2) 思路：DFS 携带路径数组 path 与长度 len；访问当前结点先入路径；若为叶子则打印当前路径；否则递归左右子树；递归返回前路径长度回退（回溯）。

```C
void PrintPath(BiTree T){
    int path[maxSize];
    DFS(T,path,0);
}
void DFS(BiTree T,int path[],int len){
    if(T==NULL) return;
    path[len++]=T->data;                       // 当前结点入路径
    if(T->lchild==NULL && T->rchild==NULL){    // 叶子：输出一条根→叶路径
        for(int i=0;i<len;i++) printf("%d ",path[i]);
        printf("\n");
        return;
    }
    DFS(T->lchild,path,len);
    DFS(T->rchild,path,len);
}
```

评分：路径维护与回溯 3 分；叶子判定与输出 3 分。时间 O(n)（每结点访问一次，输出总量为根到叶路径长度之和），递归栈空间 O(h)。

## 附录 A 全书必背结论速记（考前 3 天只看这里） {#附录-a-全书必背结论速记-考前-3-天只看这里}


### A.1 复杂度与数量级 {#a-dot-1-复杂度与数量级}

-   量级递增：O(1)&lt;O(log n)&lt;O(n)&lt;O(n log n)&lt;O(n²)&lt;O(n³)&lt;O(2ⁿ)&lt;O(n!)。
-   倍增/折半变量（i\*=2、区间减半）→ O(log n)；两层独立嵌套→O(n²)；分治对半且每层 O(n)→O(n log n)。


### A.2 线性表 {#a-dot-2-线性表}

-   顺序表：随机存取 O(1)；插入平均移 n/2、删除平均移 (n−1)/2、查找平均比较 (n+1)/2，均 O(n)。
-   链表：头插得逆序、尾插得同序；后插 `s->next=p->next;p->next=s` （顺序不可反）。
-   带头结点：空表 `L->next==NULL` ；头结点统一首元处操作。


### A.3 栈与队列 {#a-dot-3-栈与队列}

-   栈 LIFO、队列 FIFO；合法出栈序列数=卡特兰数 C(2n,n)/(n+1)。
-   循环队列（牺牲一单元）：空 front==rear；满 (rear+1)%M==front；个数 (rear−front+M)%M。
-   后缀求值：先弹为右操作数 b、后弹为左操作数 a，算 a op b。


### A.4 数组/广义表/串 {#a-dot-4-数组-广义表-串}

-   行优先 LOC(i,j)=基址+(i·n+j)L；列优先=基址+(j·m+i)L。
-   对称矩阵下三角 k=i(i−1)/2+j−1；三对角非零元 3n−2。
-   表头可原子可表， **表尾永远是表** ；长度看最外层，深度看括号最大嵌套层数。
-   BF 最坏 O(nm)；KMP=O(n+m)，主串指针不回溯。


### A.5 树与二叉树 {#a-dot-5-树与二叉树}

-   第 i 层至多 2^(i−1)；深度 k 至多 2^k−1； **n₀=n₂+1** ；n 结点完全二叉树深 ⌊log₂n⌋+1。
-   完全二叉树编号：左 2i、右 2i+1、父 ⌊i/2⌋；二叉链表空链域 n+1。
-   先+中、后+中可唯一还原；先+后不能。
-   树的先根=对应二叉树先序；树的后根=对应二叉树中序。
-   哈夫曼：总结点 2n−1、无度 1 结点、WPL=Σwₖlₖ=非叶结点权值之和、前缀码。
-   大根堆：父≥子，堆顶最大；建堆从 ⌊n/2⌋ 向下筛选。


### A.6 图 {#a-dot-6-图}

-   无向完全图 n(n−1)/2 边；有向完全图 n(n−1) 弧；度数和=2e；有向 ΣID=ΣOD=e。
-   生成树 n−1 边；邻接矩阵 O(n²)（行出列入入），邻接表 O(n+e)。
-   DFS 用栈、BFS 用队列；邻接表均 O(n+e)、矩阵均 O(n²)；BFS 求无权图最短路。
-   Prim O(n²) 稠密；Kruskal O(e log e) 稀疏（并查集判环）。
-   Dijkstra 单源 O(n²) 非负权；Floyd 全源 O(n³)。
-   拓扑排序判环 O(n+e)；AOE：ve 顺取 max、vl 逆取 min，l−e=0 为关键活动。


### A.7 排序（稳定性口诀："插冒归基"稳定，其余不稳） {#a-dot-7-排序-稳定性口诀-插冒归基-稳定-其余不稳}

| 算法 | 平均            | 最坏          | 空间          | 稳定 |
|----|---------------|-------------|-------------|----|
| 直接插入 | O(n²)           | O(n²)，最好 O(n) | O(1)          | √  |
| 希尔 | O(n^1.3)        | —             | O(1)          | ×  |
| 起泡 | O(n²)，改进最好 O(n) | O(n²)         | O(1)          | √  |
| 快速 | O(n log n)      | O(n²)         | O(log n)~O(n) | ×  |
| 简单选择 | O(n²)           | O(n²)         | O(1)          | ×  |
| 堆   | O(n log n)      | O(n log n)    | O(1)          | ×  |
| 归并 | O(n log n)      | O(n log n)    | O(n)          | √  |
| 基数 | O(dn)           | O(dn)         | O(n+r)        | √  |


### A.8 查找 {#a-dot-8-查找}

-   顺序 ASL=(n+1)/2；折半 O(log n)，仅有序顺序表；分块最优块长 √n。
-   BST 中序有序；插入为叶子；删度 2 结点用中序前驱/后继；最好 O(log n)、最坏 O(n)。
-   AVL：BF=左高−右高∈{−1,0,1}；N(h)=N(h−1)+N(h−2)+1；LL 右旋、RR 左旋、LR/RL 双旋。
-   m 阶 B 树：至多 m 子树 m−1 关键字；非根至少 ⌈m/2⌉ 子树；叶同层；分裂中关键字上提。
-   哈希：除留余数 p 取素数；线性探测易基本聚集、二次探测易二级聚集、链地址无聚集；α=n/m；ASL 只取决于 α；删除需标记；不适合范围查找。

### B.1 单链表遍历模板 {#b-dot-1-单链表遍历模板}

```C
for(p=L->next; p; p=p->next){ /* 对 p->data 处理 */ }
```

凡是"求长度/求和/最值/统计/查找定位"都是这一遍循环；涉及删除必须用 pre 跟踪前驱。


### B.2 二叉树递归三件套（绝大多数树算法都是这个骨架） {#b-dot-2-二叉树递归三件套-绝大多数树算法都是这个骨架}

```C
ReturnType f(BiTree T){
    if(T==NULL) return 边界值;              // 空树基准
    ReturnType L=f(T->lchild);              // 递归左
    ReturnType R=f(T->rchild);              // 递归右
    return 由 T->data、L、R 组合的结果;      // 后序位置合并
}
```

-   求结点数：1+L+R；求高度：max(L,R)+1；求叶子：空 0、叶子 1、其余 L+R。
-   先序处理写在递归之前、中序写在两递归之间、后序写在两递归之后。


### B.3 图遍历框架（邻接表） {#b-dot-3-图遍历框架-邻接表}

```C
void DFS(AGraph *G,int v){
    visited[v]=1; visit(v);
    for(ArcNode *p=G->adjlist[v].firstarc;p;p=p->nextarc)
        if(!visited[p->adjvex]) DFS(G,p->adjvex);
}
// 连通分量计数：外层 for 每个未访问顶点调用一次 DFS，计数+1
```
